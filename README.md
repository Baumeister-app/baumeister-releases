# Baumeister

**Baumeister (baumeister.host) is free Windows and Mac software that hosts your website, shop or app from your own computer.**

Build it with AI or upload what you have, press Publish, and it's online at a free `yourname.baumeister.host` address or your own domain. Visitors reach your computer through an outbound Cloudflare tunnel: no open ports, and your home IP stays hidden.

This repository holds Baumeister's installers and update files. Every release is listed under [Releases](https://github.com/Baumeister-app/baumeister-releases/releases).

## What it does

- Build a website, shop or app by describing it in plain words, or upload an existing site or app.
- Publish to `yourname.baumeister.host` or your own domain. HTTPS is set up for you.
- Runs static sites and Python (Flask, FastAPI) and Node.js apps, each in its own environment.
- Orders, bookings and messages land in an Inbox, with an email for each one.
- Sell with Stripe. The money goes to your own Stripe account; Baumeister takes nothing.
- Safety Net (free, opt-in): while your computer is off, visitors see the latest copy of your site and Buy buttons keep working.
- For developers: GitHub push-to-deploy, a local API, coding agents (Claude Code, Cursor, Codex), logs, restarts, and undo for the last 20 publishes.

## Price

Free, not a trial. Lite ($6.99/month) and Pro ($12.99/month) only raise limits: more web addresses, AI changes, Safety Net storage and sign-in emails. See [Pricing](https://baumeister.host/pricing).

## Requirements

Windows 10 or 11 (64-bit), or a Mac with Apple silicon (M1 or later).

## Which file to download

| You have | Download |
|---|---|
| Windows 10 or 11 | `Baumeister-Setup-<version>.exe` |
| Mac with Apple silicon | `Baumeister-<version>-arm64.dmg` |

The `.yml`, `.zip` and `.blockmap` files are for automatic updates; you don't need them.

## Security

Installers are signed. See [Security](https://baumeister.host/security) for how Baumeister protects your computer and how to report a problem.

## Optional hardware

The [Baumeister Private Server](https://baumeister.host/server) is a small always-on server that runs the same software, for people who don't want to leave a computer on. $399, one-time.
